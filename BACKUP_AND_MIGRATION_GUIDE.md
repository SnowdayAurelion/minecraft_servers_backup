# Minecraft Servers: Backup & Migration Guide

This document is a complete reference for managing, backing up, and migrating your Minecraft server infrastructure (`Erika`, `Main modded forever`, and `funland`) to a new computer.

## 2. What Is Tracked in Git vs. What Is Excluded

Your Git repository is configured to preserve complete world integrity while avoiding file churn, lock file errors, and GitHub's 100 MB file limit.

### Tracked in Git (Backed Up to GitHub)
- **World Saves**: All region chunks (`.mca`), entities, points of interest (`poi`), data files (`level.dat`, `scoreboard.dat`, `raids.dat`), and dimensions (`DIM-1` Nether, `DIM1` End, custom mod dimensions).
- **Player State**: Inventories (`playerdata/*.dat`), statistics (`stats/*.json`), advancements, and modded death chests (`world/gravestones/`).
- **Configurations**: `server.properties`, `whitelist.json`, `ops.json`, `banned-players.json`, `banned-ips.json`, `usercache.json`, `eula.txt`.
- **Mod Configurations**: All files in `Main modded forever/config/` and `defaultconfigs/`.
- **Modpack & Launchers**: `Main modded foreverrrr 1.0.4.mrpack` and the active bootstrap launcher `fabric-server-mc.26.1.2-loader.0.19.2-launcher.1.1.1.jar`.
- **Mod JARs**: All 87 mod `.jar` files in `Main modded forever/mods/` (essential to prevent modded blocks and items from being deleted upon world load).
- **Scripts**: `start_all.sh`, `scripts/mc-backup.sh`, `scripts/copy_minecraft_to_usb.sh`.

### Excluded via `.gitignore` (Not Pushed to GitHub)
- **Server Executables (`server.jar`, `minecraft_server.*.jar`)**: Vanilla Mojang binaries are excluded to prevent copyright issues and unnecessary bloat (they can be redownloaded at any time).
- **Logs (`logs/`, `*.log`, `*.log.gz`)**: Prevents Git bloat and avoids GitHub's 100 MB per-file push limit.
- **Crash Reports (`crash-reports/`)**: Temporary failure dumps.
- **Session Locks (`session.lock`, `*.lock`)**: Ephemeral lock files generated when servers run. Excluding these ensures a restored world won't mistakenly think it is already open by another process.
- **Render & Cache Data**:
  - `Main modded forever/world/voxy/` and `voxyserver/` (LevelDB voxel LOD mesh cache, automatically regenerated by the Voxy mod).
  - `.fabric/` and `libraries/` (auto-downloaded Fabric dependencies).
  - `.mixin.out/` (Fabric mixin debug bytecode dumps).
  - `config/veinminer/update/` (auto-downloaded update files).

## 3. Step-by-Step Migration Guide (Setting Up on a New PC)

Follow these steps when moving to a new computer:

### Step 1: Install System Requirements (Linux / Ubuntu / Debian)
Open a terminal on your new computer and install Java, Git, tmux, and cron:
```bash
sudo apt update
sudo apt install -y openjdk-21-jre-headless git tmux cron rsync curl
```
> **Note:** Minecraft 1.20.5+ and 1.21+ require **Java 21** or newer.

### Step 2: Set Up SSH Access to GitHub
Ensure your new computer has an SSH key linked to your GitHub account:
```bash
# Generate key if you don't have one
ssh-keygen -t ed25519 -C "your_email@example.com"

# View your public key and add it to GitHub (Settings -> SSH and GPG keys)
cat ~/.ssh/id_ed25519.pub

# Test connection
ssh -T git@github.com
```

### Step 3: Clone the Repository
Clone your backup to your Documents folder:
```bash
mkdir -p ~/Documents
cd ~/Documents
git clone git@github.com:SnowdayAurelion/minecraft_servers_backup.git MinecraftServers
cd MinecraftServers
```

Set your Git identity in this repository:
```bash
git config user.name "Alex"
git config user.email "lightningbeat80@gmail.com"
```

### Step 4: Download the Missing Server JARs
The world files, configs, and mod files are already present. You only need the server binary for `Erika`:

```bash
# 1. Download official Minecraft 1.21.10 server jar for Erika
cd ~/Documents/MinecraftServers/Erika
curl -OJ https://piston-data.mojang.com/v1/objects/1.21.10/server.jar  # Replace with exact 1.21.10 official download URL
# If official direct link has expired, download the 1.21.10 server.jar from Mojang / Minecraft launcher and name it 'server.jar'.

# 2. Main modded forever:
# NO DOWNLOAD NEEDED! The repository already contains 'fabric-server-mc.26.1.2-loader.0.19.2-launcher.1.1.1.jar'.
# When first started, the launcher automatically downloads the matching vanilla server jar into .fabric/server/.

# 3. funland (if you intend to run it):
# Place 'minecraft_server.1.7.2.jar' inside ~/Documents/MinecraftServers/funland/
```

### Step 5: Make Scripts Executable & Test Launch
```bash
cd ~/Documents/MinecraftServers
chmod +x start_all.sh scripts/*.sh

# Start both servers in tmux
./start_all.sh
```

Check that both servers are running:
```bash
tmux ls
```
You should see `erika` and `forever`. Attach to inspect them:
- To see Erika: `tmux attach -t erika`
- To see Forever: `tmux attach -t forever`
- **To exit the view without stopping the server**: Press `Ctrl+B`, then press `D`.

### Step 6: Set Up Daily Automated Backups (Cron)
On your new computer, configure cron to run the backup daily at 3:00 AM:
```bash
crontab -e
```
Add the following line at the bottom:
```cron
0 3 * * * /home/alex/Documents/MinecraftServers/scripts/mc-backup.sh >/dev/null 2>&1
```
*(If your username on the new machine is different, replace `/home/alex` with your actual `$HOME` path).*

## 4. The Backup Scripts Explained

### 1. Daily GitHub Backup (`scripts/mc-backup.sh`)
This script runs automatically every night at 3:00 AM. It safely flushes running servers to prevent chunk corruption, stages files, commits changes, and pushes to GitHub.

```bash
#!/bin/bash

# 1. Environment Setup
PATH=/usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin
export HOME=${HOME:-/home/$(whoami)}

# 2. Paths (dynamically locates repo root)
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
if [ -d "$SCRIPT_DIR/../Erika" ]; then
    SERVER_DIR="$(cd "$SCRIPT_DIR/.." && pwd)"
elif [ -d "$SCRIPT_DIR/Erika" ]; then
    SERVER_DIR="$SCRIPT_DIR"
else
    SERVER_DIR="$HOME/Documents/MinecraftServers"
fi

LOG="$HOME/Documents/mc-backup.log"

cd "$SERVER_DIR" || exit 1

echo "==== Backup started $(date) ====" >> "$LOG"

# 3. Flush live server data from memory to disk
# If servers are running inside tmux sessions, tell them to flush all chunks
if command -v tmux >/dev/null 2>&1; then
    for session in erika forever; do
        if tmux has-session -t "$session" 2>/dev/null; then
            echo "Flushing world data for tmux session: $session" >> "$LOG"
            tmux send-keys -t "$session" "save-all flush" C-m
        fi
    done
    # Give the server processes time to finish writing chunks to disk
    sleep 5
fi

# 4. Stage tracked changes (respects updated .gitignore)
git add . 2>> "$LOG"

# 5. Git Operations
if ! git diff-index --quiet HEAD --; then
    git commit -m "Auto backup $(date '+%Y-%m-%d %H:%M')" >> "$LOG" 2>&1
    git push origin main >> "$LOG" 2>&1
else
    echo "No changes detected. Skipping push." >> "$LOG"
fi

echo "==== Backup finished $(date) ====" >> "$LOG"
echo "------------------------------------" >> "$LOG"
```

### 2. Secondary Physical USB Backup (`scripts/copy_minecraft_to_usb.sh`)
If you plug in an external USB drive mounted at `/media/alex/usb`, this script uses `rsync` to make a 1:1 local physical mirror:

```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
SRC="$(cd "$SCRIPT_DIR/.." && pwd)"
DEST="/media/alex/usb/MinecraftServers"
LOG="${HOME}/backup_logs/minecraft_backup.log"

mkdir -p "$(dirname "$LOG")"

if ! mountpoint -q /media/alex/usb; then
    echo "$(date) - USB not mounted at /media/alex/usb, skipping backup." >> "$LOG"
    exit 1
fi

mkdir -p "$DEST"
rsync -a --no-owner --no-group --no-perms "$SRC"/ "$DEST"/ >> "$LOG" 2>&1
echo "$(date) - Backup completed successfully." >> "$LOG"
```

## 5. Daily Operation & Management Cheat Sheet

### Managing tmux Sessions
| Task | Command |
| :--- | :--- |
| Check running servers | `tmux ls` |
| View Erika console | `tmux attach -t erika` |
| View Modded Forever console | `tmux attach -t forever` |
| **Detach / Exit console view** | Press `Ctrl+B`, release, then press `D` |
| Stop server cleanly from outside tmux | `tmux send-keys -t erika "stop" C-m` |
| Kill a frozen session | `tmux kill-session -t erika` |

### Checking Backup Status
- Check recent backup logs:
  ```bash
  tail -n 30 ~/Documents/mc-backup.log
  ```
- Run a manual backup right now:
  ```bash
  ~/Documents/MinecraftServers/scripts/mc-backup.sh
  ```
- Check Git status:
  ```bash
  cd ~/Documents/MinecraftServers && git status
  ```

### Port Forwarding Reference (Router Configuration)
If players connect from outside your home network, ensure these ports are forwarded to your server PC's local IP:
- **Port 25565 (TCP)**: `Erika` Minecraft server
- **Port 25566 (TCP)**: `Main modded forever` Minecraft server
- **Port 24454 (UDP)**: `Main modded forever` Simple Voice Chat
